# 13. Migrate from api-db to api-db2

Date: 2026-03-05

## Status

Accepted

## Context

The legacy support for api-db.sota.org was disabled recently. All requests to that endpoint fail with HTTP 404.
New endpoints are available under https://api-db2.sota.org.uk/

## Decision

There really is no choice if we want to continue using the SOTA diploma service.

## Consequences

The SOTA diploma service returns to being functional.
